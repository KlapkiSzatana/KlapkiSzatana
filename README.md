# 👋 Cześć

Tworzę **hobbystyczne** aplikacje desktopowe i narzędzia użytkowe, głównie przy pomocy AI.

Projekty są tworzone **dla mnie**, **rodziny i znajomych** - ale śmiało możesz używać🙂

Najczęściej rozwijam projekty związane z:
- 🏠 organizacją domową,
- 📦 archiwizacją danych,
- 💰 finansami,
- 🛠️ codziennymi narzędziami użytkowymi,
- 🐧 aplikacjami desktopowymi dla **Linux** / Windows / macOS.

# 🚧 Status

Repozytoria są rozwijane.
Niektóre funkcje mogą być eksperymentalne albo jeszcze niedokończone.
