# 👋 Cześć

Tworzę hobbystyczne aplikacje desktopowe i narzędzia użytkowe, głównie przy pomocy AI.

Najczęściej rozwijam projekty związane z:
- 🏠 organizacją domową,
- 📦 archiwizacją danych,
- 💰 finansami,
- 🛠️ codziennymi narzędziami użytkowymi,
- 🐧 aplikacjami desktopowymi dla Linux / Windows / macOS.

---

## 🤖 Programowanie z AI

> „Programowanie z AI to jak jazda szybkim samochodem – zazwyczaj docierasz do celu błyskawicznie, ale czasem lądujesz w rowie.”

AI mocno przyspiesza moją pracę, ale nadal:
- testuję,
- poprawiam,
- refaktoryzuję,
- uczę się na błędach,
- i często przebudowuję rzeczy kilka razy.

Nie wszystko będzie idealne — ale każdy projekt rozwija się razem ze mną.
